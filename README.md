# TypeScript Daily Practice

Daily TypeScript and data structures & algorithms practice.

I'm using this repo to get more comfortable writing TypeScript while reviewing common coding interview patterns and JavaScript fundamentals.

## What I'm Practicing

- TypeScript types and type inference
- Arrays and strings
- `Set`
- `Record`
- Frequency counters
- Object lookups
- Early returns
- Two-pass solutions
- Tracking "best so far" values
- Common technical interview patterns

## Examples of Types I'm Using

```ts
number[]
string[]

number | null
string | null

Set<number>
Set<string>

Record<string, number>
Record<string, string[]>
```

## Running the Practice File

Type-check the project:

```bash
npx tsc --noEmit
```

Run the compiled JavaScript after compiling:

```bash
npx tsc
node practice.js
```

## Approach

The goal is not to memorize solutions.

I'm working through problems repeatedly so that common patterns become easier to recognize and so that TypeScript syntax starts to feel natural.

This repo will continue to grow as I work through more technical interview preparation.
